## 📁 Structure

```
.
├── index.html            # Page d'accueil (français)
├── en.html               # English version
├── assets/
│   ├── css/style.css     # Styles (thème clair, dégradé bleu → violet → rosé)
│   ├── js/main.js        # Animation du fond, navigation, filtres, apparitions au scroll
│   ├── img/              # Logo, favicon, illustrations, QR code
│   └── cv/               # CV en PDF
├── .nojekyll             # Sert les fichiers tels quels sur GitHub Pages
└── README.md
```

Site 100 % statique (HTML, CSS, JavaScript natif), sans dépendance ni étape de build.

## 💻 Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python -m http.server 8000
# puis http://localhost:8000
```

## 🚀 Déploiement

Le site est déployé avec **GitHub Pages** depuis la branche `main` (dossier racine).
Chaque `git push` sur `main` met le site à jour automatiquement.
